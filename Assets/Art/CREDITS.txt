3. MADE FOR THIS PROJECT

Drumstick sprite (Assets/Art/Generated/drumstick.png): drawn in code
by an editor script for this project in a flat Kenney-like style. No outside source.
Star layers and planet/asteroid-belt background layers (Assets/Art/Generated/): composed in code
from the Kenney planets and Kenney meteors above, and random dots.
The white flash shader (Assets/Art/Shaders/SpriteFlash.shader) was written for this project.
